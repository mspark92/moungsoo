# 공식 자료원·이용 조건 조사

확인일: **2026-10-18**. 공식 사이트의 안내·API 문서를 웹에서 확인했다. 아래는 수집 방법을 정하기 위한 조사이며, 앱이 해당 API에 실제 연결되었거나 모든 최신 자료를 보유했다는 보고가 아니다. 기계 판독용 상세 기록은 [research-sources.json](./research-sources.json)에 있다.

## 운영 원칙

- 등록한 공식 API를 우선한다. API 키와 사용 승인 없이 안내의 `OC=test`를 실사용 자격으로 간주하지 않는다.
- API로 본문 검색이 된다는 사실과 문서 전문을 받았다는 사실을 구분한다. 제목·링크·식별자만 받은 자료는 본문 미확보이며, 내용 요약이나 생성 답변의 근거로 사용하지 않는다.
- 공개 페이지, 다운로드 버튼, `robots.txt`만으로 자동 수집·재게시가 허용됐다고 판단하지 않는다. 이번 조사에서 대량 크롤링은 실행하지 않았다.
- 안내서·서식의 공공누리 유형·제3자 권리·변경 및 상업 이용 제한은 **개별 문서**별로 확인한다. 미확인 자료는 공식 원문 링크로 제공한다.
- 출처, 문서 식별자, 확보 범위, 공포일·시행일·문서일자, 수집일·확인일을 별도로 남긴다. 링크 연결 성공을 자료 최신성 확인으로 표시하지 않는다.

### 법제처: 사용할 수 있는 공식 경로

[공식 API 전체표](https://open.law.go.kr/LSO/openApi/guideList.do)는 현행·연혁 법령과 본문·조항호목 및 공정위·조세심판원 자료를 구분한다. [현행법령 목록 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsNwListGuide)는 OC 필수, 법령 일련번호, 공포·시행일, 원문 링크 필드를 설명한다.

[공동활용 신청·주의사항](https://open.law.go.kr/LSO/usrJoin.do)은 등록 OC, 활용 목적과 도메인 입력, 신청 자동승인을 안내한다. 출처 누락·위변조·제3자 권리 침해를 금지하고 과도한 API 호출 및 정책 변경에 따른 제한을 고지한다. 법령의 정확한 적용 검토 시 원기관과 관보 등도 확인해야 한다.

[공공데이터포털의 법제처 공유서비스](https://www.data.go.kr/data/15000115/openapi.do)는 별도 인증 경로다. 무료·출처표시 제1유형·개발계정 10,000·운영계정 트래픽 증가 신청 가능으로 표기한다. 이를 OC 직접 API의 무제한 호출 보장으로 읽어서는 안 된다.

### 국세청: 목록과 본문을 구분해야 하는 지점

[국세법령정보시스템](https://taxlaw.nts.go.kr/) 메뉴에서 조세법령·기본통칙·집행기준·사전답변·질의회신·판례·서식·발간책자를 확인했다. 전자도서관은 조회·다운로드를 안내한다.

[국세청 해석례 API](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=cgmExpcNtsListGuide)는 `ntsCgmExpc` **목록** 서비스다. 안건명·안건번호·기관·해석일·데이터기준일시·상세링크를 돌려주며, 본문 검색 옵션이 있어도 전문 수신을 뜻하지 않는다. [전체 API 표](https://open.law.go.kr/LSO/openApi/guideList.do)의 국세청 본문 칸은 `-`로 표시되어 있다.

[국세청 저작권정책](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8169&mi=6791)의 본문은 [국세청 공식 webtv 서브도메인](https://webtv.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8169&mi=6791)에서 확인했다. 공공누리 유형과 출처 표시를 준수해야 하며, 표시 없는 자료는 담당자와 사전 협의를 안내한다. 대량 웹 자동 수집을 허용한다는 근거는 확인하지 못했다.

### 조세심판원·공정위: 공식 API를 통한 보완

[조세심판원 API 본문 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=specialDeccTtInfoGuide)는 `ttSpecialDecc`의 사건·청구번호, 의결일, 세목, 재결요지, 주문, 이유, 관련법령 등을 설명한다. [목록 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=specialDeccTtListGuide)도 제공한다. [조세심판원 홈페이지](https://www.tt.go.kr/) 첫 화면은 이번 브라우저의 본문 추출이 비어 원사이트 전체 정책 확인에 한계가 있었다.

[공정위 결정문 API 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=ftcInfoGuide)는 `ftc` 의결서·시정권고서의 사건번호, 결정번호, 주문·이유·적용법조 등을 명시한다. [공정위 공공데이터 API 소개](https://www.ftc.go.kr/www/contents.do?key=257)는 별도 제공 데이터 안내이며 모든 의결서의 전문 API를 보장하는 근거로 쓰지 않았다.

[공정위 저작권정책](https://www.ftc.go.kr/www/contents.do?key=520)은 검색 색인에서 공공누리 유형별 조건을 확인했지만 직접 페이지 열기는 실패했다. [하도급 정책자료](https://www.ftc.go.kr/www/selectBbsNttList.do?bordCd=101&key=725&searchViolt=000021)와 [공정거래협약 자료실](https://gowith.ftc.go.kr/www/selectBbsNttList.do?bbsNo=2&key=219&pageIndex=1&searchCnd=all)의 가이드·FAQ·계약서 게시물은 파일별 이용 조건 확인 전에는 링크로 연결한다.

### 법원: API 소개와 실제 사용 가능 상태를 구분

[공식 이용 절차](https://openapi.scourt.go.kr/kgso202m01.do)는 직접 오픈API를 추후 업데이트 예정으로 안내하고, 연계 API는 담당자에게 별도 문의하도록 한다. 회원가입·신청·승인·키 발급의 절차가 있다는 사실만으로 지금 사용할 수 있다고 표시하지 않는다.

[사법정보공유포털 저작권정책](https://openapi.scourt.go.kr/kgso000m04.do)은 권리 전부를 가진 자료의 자유이용·구체적 출처 표시와 직접 링크 시 정책도 함께 연결할 것을 안내한다. [법원 대국민 서비스 소개](https://www.g.scourt.go.kr/judiciary/information/public/index.html)는 공개 판결서의 비실명화·비공개 기준을 설명한다. [법고을 LX 안내](https://lx.scourt.go.kr/sitemap)에서 판례와 참조조문의 열람 범위를 확인할 수 있다.

### 지방세

지방세는 국세와 구분한다. 국가법령정보센터의 [지방세법 특정 버전](https://law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260102&lsiSeq=276349&urlMode=lsInfoP), [행정안전부 고시·훈령 게시판](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardList.do?bbsId=BBSMSTR_000000000016&pageIndex=9), [지방세 법령정보시스템의 개별 결정례](https://olta.re.kr/explainInfo/judgeDecisionDetail.do?num=60083224) 등 출처를 분리한다. 지방세 포털 자체의 API·대량 다운로드·편집 해설 재게시 권한을 확인하지 못했으므로 지방세 전체가 수집됐다고 표시하지 않는다.

## 첫 버전의 안전한 표시

API 키가 없으면 **미연동**, 이전에 성공한 갱신이 실제 요청 오류로 실패하면 **갱신 실패**로 구분한다. 관리자가 확인한 공식 링크·본문 발췌·허용 파일만 검색 대상에 넣고 현재 수록 범위를 명시한다. 과거 시행구간을 확보하지 못한 기준일은 **해당 시점 자료 미확보·확인 불가**로 안내한다. 사이트 연결 확인일은 법령의 최신 확인일과 다르다.

이 조사에서 유료 서비스 가입·결제, 기관 계정 생성, API 인증키 발급, 로그인 제한 우회, 대량 크롤링은 수행하지 않았다.


## 2026-10-20 국세청 실무 자료 추가

기존 법인세 신고안내 1건에 공식 링크 22건을 추가하여 실무 자료를 23건으로 구성했다. 법인세 신고절차·유의사항·무실적 간편신고·중간예납·신고안내 동영상, 부가가치세 신고·납부 안내, 원천세·지급명세서, 종합소득세·연말정산·양도소득세·상속세·증여세, 납부·등록·세무서식 검색을 포함한다. 세부 출처와 대조 기록은 [nts-guide-sources.json](./nts-guide-sources.json)에 저장했다.

검색 색인에 남은 옛 콘텐츠 번호와 메뉴 번호의 잘못된 조합은 제목과 실제 본문이 달라질 수 있어, 공식 메뉴 링크와 본문 세목·제목을 대조했다. 작성일이 없는 상시 안내는 게시일을 null로 두었다. 연말정산 등 명시된 귀속연도만 기록하고 안내 연도를 임의로 귀속연도로 바꾸지 않았다.

국세청 정책은 공공누리 제1유형 표시를 확인한 뒤 이용하고, 미부착 자료는 담당자 협의를 거치도록 안내한다. 이번 자료별 본문·첨부의 자유 재게시 조건은 확인하지 못했으므로 링크 방식만 공개한다. PDF·HWP·영상 대본이나 첨부파일을 앱에서 재배포하거나 본문을 읽은 것처럼 요약하지 않는다. 이 목록은 수동 확인한 범위이며 국세청 전체 게시물 수집·자동 갱신이 아니다.

## 2026-10-20 추가 확인: 상속·증여 자료실과 국세 판례

[사용자 지정 국세청 자료실](https://www.nts.go.kr/nts/na/ntt/selectNttList.do?mi=40552&bbsId=50790)은 상속·증여 안심 가이드 게시판이다. 확인 당시 1페이지, 전체 4건이었으며 기존 2건에 2024-06-04 「국세청-상속·증여 세금상식Ⅱ」와 2023-04-28 「국세청-상속 · 증여 세금상식」 2건을 추가했다. 실무 자료는 총 25건의 공식 링크이며 본문·첨부는 재게시하지 않는다. 이전 게시 자료에 이후 개정사항이 반영되었다고 가정하지 않는다.

[판례 목록 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=precListGuide)는 `target=prec`, `datSrcNm=국세법령정보시스템` 필터를 지원한다. [본문 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=precInfoGuide)는 국세청 판례 본문을 HTML로만 제공한다고 명시한다. [공동활용 이용 조건](https://open.law.go.kr/LSO/usrJoin.do)의 출처 표시·신청 범위·과도한 호출 제한을 준수한다. 법제처를 경유한 자료에는 법제처 제공과 원 데이터 출처를 함께 기록하며 승인 OC를 서버에서만 사용한다. 사이트 자체의 숨은 AJAX·세션 주소를 수집하지 않는다.

수집 기능은 페이지당 최대 20건, 본문 검증 실패 시 링크만 보관, 검토 대기 후 관리자 공개 방식이다. 현재 실제 실행은 공식 API 연결 실패로 종료되어 갱신 실패로 표시한다. API 성공을 대신하는 것으로 표현하지 않고, 공식 상세 링크를 확인한 판례 8건을 별도로 링크 자료로 추가했다. 이 8건의 본문·국세청 요지는 확보하거나 재게시하지 않았으며 AI 근거로 사용하지 않는다. 메타데이터 확인 기록: [nts-court-link-sources.json](./nts-court-link-sources.json).

## 2026-10-20 법령 원문 주소 수정

전문 8건의 생성된 `/법령/이름/시행일/번호` 주소가 오류 페이지를 반환해 [법제처 공식 한글주소 규칙](https://open.law.go.kr/LSO/lab/hangulAddr.do)의 `(시행일,공포번호,공포일)` 형식으로 수정했다. 부가가치세법은 공식 페이지에서 관찰한 같은 버전의 직접 링크로 연결한다. 원문 진입 페이지 8건의 HTTP 200과 제목·시점 매개변수를 확인했으며 본문 자체의 수집·확인일은 변경하지 않았다. [연결 확인 기록](./law-source-links-2026-10-20.json).
