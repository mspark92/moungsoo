# 모바일 하단 메뉴

850px 이하 화면에서는 주 메뉴를 화면 하단에 고정하고 가로 한 줄로 배치한다. 폭이 부족하면 좌우로 스크롤할 수 있다. 선택한 메뉴를 자동으로 보이는 범위로 이동시키며 방향키·Home·End·Enter로도 조작할 수 있다. 본문 하단에는 메뉴 높이와 기기 안전 영역을 고려한 여백을 둔다. PC의 기존 왼쪽 사이드바와 원문·검색 기능은 유지한다.

검증: 자동 테스트 12개 파일 통과. 실제 앱 자산과 검색 모듈 응답을 사용한 격리 브라우저에서 320·375·430·768·850px의 하단 고정 위치·가로 넘김·메뉴 선택·선택 항목 표시·본문 겹침 방지·키보드 이동을 확인했다. 1440px의 PC 사이드바 유지와 브라우저 JavaScript 오류 없음을 확인했다. 실제 휴대전화 기기에서의 터치 검증은 수행하지 않았다.
