# 관계 법령 목록 변경 검증

관계 법령 메뉴는 법률·시행령·시행규칙을 법령명 단위로 표시한다. 조문·부칙 본문 8건과 기존 조문 11건을 8개 법령으로 묶는다. 판례·해석례·고시·안내서는 이 메뉴에서 제외하며, 통합 검색에서는 기존 자료를 유지한다.

법령명 선택 시 공식 법령 전체 원문 링크와 앱의 확보 범위를 제공한다. 앱에 전문을 확보하지 않은 법령을 전문 확보로 표시하지 않는다. 수록 조문·버전은 상세 안의 접힌 목록에서 확인한다.

검증은 실제 앱 HTML/CSS/JavaScript를 Chromium에 로드하고 공개 API 응답을 격리된 fixture로 제공해 수행했다. 실제 법제처 서버의 전문 다운로드 성공을 이 검증으로 주장하지 않는다.

검증 결과:

- PC: 8개 법령명, 법인세법 중복 묶음, 조문별 카드 숨김, 법령 유형 필터 제한 — 통과
- 상세: 공식 전체 원문 새 창 링크와 전문 미확보 안내, 수록 조문·버전 펼침 및 기존 원문 열람 — 통과
- 세무 6개, 하도급 법률·시행령 2개 필터 — 통과
- 법인세법 제19조 검색에서 법인세법 부모 항목 1개 표시 — 통과
- 375px 모바일 목록·상세·닫기·가로 넘침 없음 — 통과
- 브라우저 JavaScript 오류 없음 — 통과
- category=laws 서버 필터·충돌하는 유형·결과 제한 전 필터·조문·과거 기준일 — 신규 테스트 5개 통과
- 전문 검색 정확도·확인일 범위·부칙/주 조문 구분 — 신규 테스트 6개 통과
- 기존 관리자 권한·일정 서명·갱신·자료 검색 회귀 테스트 — 통과

원격 저장소의 추가 API 조문·부칙 본문 8건을 병합해 보존했다. 별표·서식 파일 및 모든 과거 버전은 미확보다. 외부 API의 현재 연결 성공은 이 UI 검증의 범위가 아니다.
