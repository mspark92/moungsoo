# 법령 단위 목록 및 최근 변경사항 분리

2026-10-20 확인.

- 관계 법령과 통합 검색의 법령 결과는 법령명 단위로 묶는다. 법인세법 제19조·제116조 등의 자료가 개별 검색 항목으로 다시 표시되지 않는다.
- 최근 변경사항은 홈의 별도 영역과 개정사항 메뉴에서 공포일 순으로 표시한다. 같은 공포번호·공포일·시행일의 조문 자료는 하나로 묶고, 해당 버전의 전문을 우선한다.
- 개정 내용 해설을 확보한 자료는 없으므로 변경 내용을 추정해 작성하지 않는다. 공식 제·개정문과 부칙 확인을 안내한다.
- 저장 자료·과거 버전·실제 조문 본문은 보존한다. 보관함의 제목만 법령명으로 표시하며, 저장 범위와 버전은 그대로 확인할 수 있다.
- 공식 원문 파일과 별표·서식은 국가법령정보센터의 원문다운로드로 안내한다.

검증:

1. Node 테스트 8개 파일 통과. 신규 개정사항 검증 3개, 법령 목록·과거 자료 보존 검증 3개를 포함한다.
2. Chromium 격리 API fixture에서 실제 화면 코드 검증 12항목 통과: 법령 8종·세무 6종·하도급 2종, 조문 검색 부모 항목, 통합검색 중복 제거, 전문 문자 보존·목차·문서 검색, 홈 변경사항 분리, 공포일 정렬·해설 미확보 표시, 모바일 목록·원문·개정사항 가로 넘침 없음, 과거 보관함 본문·버전 보존, JavaScript 오류 없음.
3. Worker 번들 빌드 성공. 법령·사례 데이터와 서버 권한·갱신 API 구현은 변경하지 않았다.

브라우저 검증은 공식 API의 실시간 수집이나 개정 해설 검토를 대신하지 않는다.
