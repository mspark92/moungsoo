## 1. 국가법령정보 공동활용 OC 발급 (무료)

법령·판례를 공식 API로 가져오려면 OC가 필요합니다. 이 OC가 없으면 2~5번을 진행할 수 없습니다.

1. https://open.law.go.kr/ 에 접속해 **회원가입**한 뒤 로그인합니다.
2. 상단 **OPEN API → OPEN API 신청**에서 신청서를 작성합니다.
   - 신청 서비스는 **법령(현행법령·시행일법령)**과 **판례**를 반드시 포함하세요.
   - 활용 도메인 입력란에 운영 주소 `business-legal-tax-reference.myoungsoo1.chatgpt.site`를 적습니다. 신청서에 IP 입력란이 있고 내 PC에서도 수집할 계획이면 내 PC의 공인 IP도 함께 적으세요.
3. 승인 후 마이페이지의 신청 내역·인증값 화면에서 **OC 값**(공식 안내상 "신청한 API 인증값")을 확인합니다.

> **중요 (2026-10-21 확인)**: 법제처는 OC 신청 때 등록한 **IP·도메인에서 온 요청만** 받습니다. 운영 사이트 서버(Cloudflare)는 IP가 고정되지 않아 "사용자 정보 검증에 실패하였습니다"로 거절될 수 있습니다. 그래서 운영 사이트에서 직접 수집이 안 되면 **내 PC에서 수집해 파일로 올리는 방식**(아래 4·5번의 "내 PC에서" 안내)을 쓰면 됩니다. 국세법령정보시스템 판례에 별도로 신청할 API 권한은 없습니다. 법제처 판례 API와 같은 OC를 씁니다.

## 3. 운영 사이트에 OC 등록

1. 운영 사이트 → **자료 관리**에서 관리자로 로그인합니다.
2. **법령 자동 갱신** 칸에 1번에서 받은 OC를 입력하고, "공동활용 승인과 이용 조건을 확인했습니다"를 체크한 뒤 **서버에 등록**을 누릅니다.

## 4. 최근 2년 판례 수집과 공개

1. **자료 관리 → 판례 수집 · 최근 2년**을 엽니다. 기간은 오늘 기준 최근 2년으로 자동 입력되어 있습니다.
2. 세 가지 범위를 모두 체크한 채 **수집 시작**을 누릅니다.
   - 국세법령정보시스템 판례: 약 5,000건(2026-10-21 기준), 제목·사건번호·선고일·링크
   - 대법원 출처 세법·지방세 판례: 공식 판결문 포함
   - 하도급 관련 판례: 공식 판결문 포함
3. 화면을 열어 둔 채 기다립니다. 중간에 멈추거나 창을 닫았다면 다시 들어와 **이어서 수집**을 누르면 됩니다.
4. 끝나면 아래 **판례 검토 대기**에서 몇 건을 열어 원문 링크를 확인합니다. 그다음 "이 범위 …건의 출처·본문 범위·이용 조건을 확인했고 공개합니다"를 체크하고 **이 범위 전체 공개**를 누릅니다.

**"연결 실패"나 "다른 주소로 이동" 오류가 나면** 운영 서버가 law.go.kr에 접속하지 못하는 상황입니다. 이때는 내 PC에서 수집합니다.

```
cd moungsoo
copy .env.example .env      (메모장으로 .env를 열어 LAW_API_OC= 뒤에 OC 입력)
npm run collect:cases
```

수집이 끝나면 `exports/cases-날짜_날짜.json` 파일이 생깁니다. 운영 사이트 **판례 수집 → 수집 파일 올리기**에서 이 파일을 선택하고, 이후 공개 절차는 위 4번과 같습니다. 수집이 중간에 끊겨도 같은 명령을 다시 실행하면 이어서 진행합니다.

## 5. 법령 32종 전문 공개 (시행령·시행규칙 포함)

관계 법령은 국세 6법·지방세 4법과 각 시행령·시행규칙, 하도급법·시행령까지 32종입니다. 하도급법은 시행규칙이 없습니다. 새로 추가한 20종(시행령·시행규칙)과 지방세 4법은 처음에는 공식 원문 링크만 있습니다.

1. **법령 자동 갱신 → 현재 버전 본문 다시 받기**를 누릅니다. 32종 전부의 현재 공식 본문을 받아 검토 대기에 올립니다(약 20초).
   - 2026-10-21에 대조한 결과, 앱에 원래 있던 국세기본법·부가가치세법·조세특례제한법 전문은 시행일이 같은데도 공식 본문과 일부 문장이 달랐습니다. 소득세법·법인세법·상속세및증여세법은 새 버전이 나와 있습니다. 이 단계를 거치면 모두 공식 본문으로 맞춰집니다.
2. **법령 검토 대기**의 법령마다 **공식 원문 ↗**으로 시행일·공포일을 대조합니다. 확인란을 체크한 뒤 **전문 공개**를 누릅니다. 같은 버전이 이미 있으면 본문만 교체합니다.
3. 이후에는 평일 9시 정기 갱신이 하루 16종씩 번갈아 새 버전을 확인합니다. 바로 확인하려면 **지금 갱신 확인**을 누르세요.

**운영 사이트에서 "법제처 응답: 사용자 정보 검증에 실패" 오류가 나면** 운영 서버 IP가 OC에 등록되지 않은 상황입니다. 이때는 내 PC에서 수집합니다.

```
npm run collect:laws
```

수집이 끝나면 `exports/laws-날짜.json` 파일이 생깁니다(약 18MB, 별표 제외). 운영 사이트 **법령 자동 갱신 → 법령 파일 올리기**에서 이 파일을 선택하고, 이후 공개 절차는 위 2번과 같습니다. 새 법령이 나오면 같은 방법을 반복하세요. 운영 사이트의 정기 갱신이 계속 실패로 표시되면 이 방법이 유일한 경로입니다.

## 6. (선택) 공휴일 제외용 특일 정보 키

평일 9시 자동 갱신이 공휴일에도 돌지 않게 하려면 등록합니다.

1. https://www.data.go.kr/ 에 회원가입하고 **"한국천문연구원_특일 정보"**를 검색해 **활용신청**을 합니다(자동 승인).
2. 마이페이지 → 개발계정에서 **일반 인증키(Decoding)**를 복사합니다.
3. ChatGPT(Sites) 작업 창에서 운영 서버 환경 변수 `HOLIDAY_API_KEY`에 이 값을 등록하고 재배포하도록 요청합니다. 키 값은 그 작업 창의 비밀값 입력란에만 넣으세요.
4. 등록 후 **자료 관리 → 올해 공휴일 확인**을 눌러 목록이 나오면 완료입니다.

## 7. (선택) 국세청 실무 자료 본문

국세청 신고 안내 25건의 페이지에는 공공누리 표시가 없습니다. 국세청 저작권정책상 이런 자료는 담당 부서와 사전 협의가 필요해서, 지금은 원문 링크만 제공합니다. 본문을 앱에 싣고 싶다면 [국세청 저작권정책](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8169&mi=6791) 페이지의 안내에 따라 이용 허락을 문의하세요. 허락받은 범위를 알려주시면 그 범위만큼 반영합니다.
