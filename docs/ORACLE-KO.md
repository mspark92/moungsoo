# 오라클 클라우드 상시 무료 서버로 옮기기

Cloudflare Workers는 요청당 메모리 128MB(유료도 같음) 한도 때문에 법령 전문 32종과 판례를 함께 실을 수 없었습니다. 오라클 클라우드의 상시 무료(Always Free) 가상 서버는 PC처럼 Node.js가 계속 실행되는 일반 서버입니다. 그래서 다음이 가능해집니다.

- 내 PC 앱과 똑같이 법령 32종 전문과 판례 전체를 인터넷 주소에서 쓸 수 있습니다.
- 서버 IP가 고정되므로 법제처 OC에 등록하면 **평일 9시 자동 갱신**이 다시 동작합니다.

## 운영자가 직접 할 일 (가입·결제·키 등록은 본인만 가능)

### 1. 오라클 클라우드 가입 (약 15분)

1. https://www.oracle.com/kr/cloud/free/ 에서 **무료로 시작하기**를 누릅니다.
2. 국가는 대한민국, 이메일·이름을 입력하고 메일 인증을 합니다.
3. **홈 리전**은 `South Korea Central (Seoul)` 또는 `South Korea North (Chuncheon)`을 고르세요. 홈 리전은 나중에 바꿀 수 없습니다.
4. 신용·체크카드로 **본인 확인**을 합니다. 무료 계정이라 확인용 소액 승인 후 취소되며, 유료로 업그레이드하지 않는 한 청구되지 않습니다. 정확한 조건은 가입 화면 안내를 확인하세요.

### 2. 서버(인스턴스) 만들기 (약 10분)

1. 콘솔 메뉴 **컴퓨트 → 인스턴스 → 인스턴스 생성**을 엽니다.
2. 이름은 `moungsoo`로 하고, 이미지는 **Canonical Ubuntu 24.04**(또는 22.04)를 고릅니다.
3. Shape는 둘 중 하나를 고릅니다.
   - 권장: **VM.Standard.A1.Flex** (Ampere, "Always Free 사용 가능" 표시) · OCPU 1~2, 메모리 6~12GB
   - "용량 부족(Out of capacity)"으로 안 만들어지면: **VM.Standard.E2.1.Micro** (메모리 1GB). 이 앱은 이것으로도 동작합니다.
4. 네트워킹은 기본값(새 VCN, 공용 서브넷, **공용 IPv4 주소 할당**)으로 둡니다.
5. SSH 키는 **키 쌍 생성 → 개인 키 저장**을 눌러 `.key` 파일을 받습니다. 이 파일은 서버 열쇠이니 잃어버리지 말고 다른 사람에게 보내지 마세요.
6. **생성**을 누르고 상태가 "실행 중"이 되면 **공용 IP 주소**를 확인합니다.

### 3. 웹 포트 열기 (약 3분)

1. 인스턴스 화면에서 **서브넷** 링크를 누르고, **보안 목록 → Default Security List**를 엽니다.
2. **수신 규칙 추가**를 누르고 아래처럼 두 번 추가합니다.
   - 소스 CIDR `0.0.0.0/0`, IP 프로토콜 TCP, 대상 포트 `80`
   - 소스 CIDR `0.0.0.0/0`, IP 프로토콜 TCP, 대상 포트 `443`

### 4. 저에게 알려주실 것

- 서버 **공용 IP 주소**
- 받은 **개인 키 파일이 이 PC 어디에 있는지**(예: `다운로드\ssh-key-2026-10-25.key`). 파일 내용은 채팅에 붙이지 마세요.

### 5. 법제처에 서버 IP 등록

open.law.go.kr → 마이페이지 → OPEN API 신청 정보에서 서버 공용 IP를 추가합니다. 기존 PC IP는 그대로 둡니다.

## 제가 하는 일 (위 4번을 알려주시면)

1. 이 PC에서 SSH로 서버에 접속해 `deploy/oracle/setup.sh`를 실행합니다.
   - Node.js 24, Caddy(HTTPS 자동 인증서), 앱 서비스, 평일 09:00 갱신 타이머를 설치합니다.
   - 서버 내부 방화벽에서 80·443을 엽니다. 오라클 우분투 이미지는 기본으로 막혀 있습니다.
2. 주소는 `공용IP를-대시로.sslip.io`(예: `1-2-3-4.sslip.io`) 형태입니다. 가입 없이 HTTPS가 붙고, 나중에 본인 도메인으로 바꿀 수 있습니다.
3. 관리자 토큰과 갱신 서명 키는 **서버 안에서 생성**해 `/etc/moungsoo/env`(관리자만 읽기)에 둡니다. OC도 그 파일에만 넣습니다.
4. 법령 32종 파일과 판례 파일을 관리자 화면 업로드로 올립니다. 검토 후 공개는 함께 확인합니다.
5. 전체 자료를 넣은 상태에서 검색 속도와 안정성을 측정해 보고드립니다.

## 운영 메모

- 앱 갱신: `cd /opt/moungsoo && sudo git pull && sudo systemctl restart moungsoo`
- 상태 확인: `systemctl status moungsoo`, `systemctl list-timers moungsoo-update.timer`, `journalctl -u moungsoo-update -n 20`
- 자료 위치: `/var/lib/moungsoo` (백업 대상)
- 오라클 정책상 상시 무료 Ampere 서버가 오랫동안 거의 쓰이지 않으면 회수될 수 있다는 안내가 있습니다. 가입 시 안내되는 최신 조건을 확인하세요.
