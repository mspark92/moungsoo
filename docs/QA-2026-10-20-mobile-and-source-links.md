# 모바일 메뉴와 법령 원문 링크 수정

모바일·태블릿(850px 이하)에서는 메뉴 버튼 아래에 주 메뉴 7개가 세로로 펼쳐진다. 메뉴는 문서 흐름 안에 있어 본문을 아래로 밀며, 화면을 덮거나 옆에서 밀려오지 않는다. 선택·Escape·바깥 클릭으로 닫히며 펼침 상태를 `aria-expanded`로 알린다. 관계 법령의 열람 버튼과 외부 링크, 상세 조건, 검색 결과는 아래 방향으로 배치한다. PC에서는 기존 고정 사이드바를 보존한다.

전문 8건의 외부 주소가 문서화되지 않은 `/법령/이름/시행일/번호` 형식으로 생성되어 오류 페이지로 연결되는 문제를 확인했다. 법제처 한글주소 안내의 `/법령/이름/(시행일,공포번호,공포일)` 형식으로 수정했다. 부가가치세법의 한글주소는 HTTP 502여서, 앞서 공식 페이지에서 관찰한 같은 버전의 직접 주소(`lsiSeq=276117`, `efYd=20260102`)를 사용하고 제목·시행일·공포번호 응답을 확인했다. 법령 내용이나 법령 확인일·시행일은 변경하지 않았다.

기존 R2 문서는 알려진 잘못된 주소와 정확히 일치할 때만 링크를 보정한다. 관리자 수정 주소·본문·메모·과거 버전은 보존한다. 기존 로컬 보관함 스냅샷도 같은 버전의 외부 링크만 보정한다. 법령 목록에는 **앱에서 전문 읽기** 버튼을 별도로 제공한다.

검증:

- 자동 테스트 12개 파일 통과: 8개 주소, 버전·본문 보존, R2 보정과 관리자 변경 보존, 과거 자료 보존, 기존 로컬 스냅샷 URL 보정 포함.
- 실제 HTTP 확인: 공식 원문 진입 페이지 8건 HTTP 200, 제목·버전 매개변수 확인. 오류 페이지의 HTTP 200 응답을 성공으로 세지 않았다. 구체적인 확인 범위는 `law-source-links-2026-10-20.json` 참조.
- 격리 브라우저: 실제 앱 자산·검색 모듈 응답으로 1440px PC 사이드바 보존 및 전문 8건 본문 일치, 320·375·430·768·850px 메뉴 세로 배치와 본문 아래 이동, 메뉴 상태·Escape·선택 시 닫힘, 가로 넘침 없음, 전문 열람·기존 보관함 링크 보정·JS 오류 없음을 확인했다.
- 통합 검색의 조문·항·호, 원문 행 위치 이동, 관계 법령 목록 유지도 기존 브라우저 검증으로 확인했다.

외부 원문의 네트워크 확인은 이 실행 환경에서 수행했다. 개별 사용자의 외부 브라우저 접속을 모두 재현한 결과는 아니다. 앱 내부에서는 외부 연결 없이 확보한 전문을 열람할 수 있다.
