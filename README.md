# 기업 법무·세무 레퍼런스 — 웹앱

기존 Node/SQLite 실행본의 화면·공식 자료·검색 규칙을 보존하여 Sites의 서버리스 웹앱으로 옮긴 버전입니다.

- 공식 확인 자료 72건(초기 시드): 세무 59, 하도급 13. 판례 24건(발췌 16건·링크 8건), 법령 발췌·안내서 포함. 조문·부칙 본문 8건·발췌 27건·제목/링크만 확보 37건(지방세 법령 4종 공식 원문 링크 포함).
- 관계 법령 32종(2026-10-21): 국세 6법·지방세 4법과 각 시행령·시행규칙, 하도급법·시행령. 새 20종과 지방세 4법은 공식 원문 링크로 시작하며, 관리자 화면의 **현재 버전 본문 다시 받기 → 검토 → 전문 공개**로 조문·부칙 전문을 넣습니다(별표는 공식 원문). 같은 버전이 이미 있으면 본문만 교체합니다.
- 판례 대량 수집(2026-10-21 추가): 관리자 화면에서 선고일 기준 최근 2년의 국세법령정보시스템 판례(제목·링크), 대법원 출처 세법·지방세 판례와 하도급 판례(공식 판결문)를 페이지 단위로 수집해 검토 대기에 두고, 관리자 확인 후 일괄 공개합니다. 운영 서버가 law.go.kr에 연결하지 못하면 `npm run collect:cases`로 내 PC에서 수집한 파일을 올립니다.
- **운영자가 직접 할 일은 [docs/USER-TODO-KO.md](./docs/USER-TODO-KO.md)에 순서대로 정리했습니다.**
- 검색·필터·원문·버전·로컬 보관함·관리자 검토/공개 관리.
- 관계 법령은 법률·시행령·시행규칙만 법령명 단위로 묶어 표시합니다. 조문과 버전은 법령 상세 안에서 확인합니다. 현재 초기 자료는 8개 법령의 조문·부칙 본문과 일부 조문 11건입니다. 별표·서식은 공식 사이트에서 확인합니다.
- 관리자 변경 자료는 서버의 R2 영구 저장소에 저장합니다. 저장소가 연결되지 않은 경우 등록·수정 API를 서버에서 거절합니다.
- 관리자 접근은 Sites가 확인한 사용자 정보와 명시적 운영자 allowlist를 비교합니다. 임의의 로그인 사용자에게 관리자 권한을 주지 않습니다.
- 승인된 OC가 등록되면 주요 법령 8종의 공식 API 응답을 수집해 검토 대기로 보관합니다. OC 등록 상태와 수집 성공 여부는 관리자 연결 상태에서 각각 확인합니다. AI 답변은 미연동입니다. AI 없이 기본 기능이 작동합니다.
- 보관함은 브라우저 로컬 저장소이며 기기 간 동기화가 없습니다.
- 실무 자료: 국세청 신고·납부 안내 링크 25건. 상속·증여 안심 가이드 게시판 4건을 포함합니다. 세목별 필터와 직접 원문 열람을 제공하며, 본문·첨부는 미수록으로 AI 근거에서 제외합니다. 이 자료의 정기 수집은 미연동이며 평일 09시 법령 갱신과 구분합니다.

[CLAUDE.md](./CLAUDE.md)와 [인수인계 설명서](./docs/CLAUDE-HANDOFF-KO.md)를 먼저 읽으세요. Node.js 24 이상에서 추가 패키지 없이 로컬로 실행할 수 있습니다.

```sh

npm run dev
```

## 빌드

Node.js 24 이상. 외부 패키지 설치가 필요 없습니다.

```sh
npm run build
npm test
```

`scripts/build.mjs`는 추적된 `public/`, `data/seed.json`, `lib/search.mjs`, `worker/runtime.mjs`를 하나의 Worker 파일로 묶습니다. 공식 Worker ESM 스타터의 아티팩트 구조(`dist/server/index.js`, `dist/.openai/hosting.json`)를 사용합니다. 생성된 `worker/index.js`를 직접 수정하지 않습니다.

현재 실행 환경에는 Sites의 프로젝트 준비·소스 workflow 도우미가 설치되지 않아, 읽을 수 있는 공식 Worker 스타터 계약을 따르는 빌드와 credential-safe Git 전송을 사용했습니다. 네이티브 Sites가 생성한 동일한 project_id·원격 저장소를 유지하고, 정확히 push한 commit과 그 소스에서 빌드한 archive만 저장·배포합니다. Git 토큰은 메모리와 자식 프로세스 환경에서만 사용하며 파일·명령 인자·로그에 쓰지 않습니다.

## 운영

`.openai/hosting.json`은 Site 식별자와 R2 논리 바인딩만 저장합니다. 실제 API 키·관리자 인증값은 Sites의 서버 환경 변수에만 보관하세요. 사용자가 요청한 링크 공개 범위로 운영합니다. 공개 검색·원문 열람은 로그인 없이 가능하며, 관리자 변경은 서버의 명시적 권한 검사로 제한합니다.

- `ADMIN_EMAIL` 또는 `ADMIN_USER_ID`: 명시적 관리자 allowlist. Sites에서 검증해 전달한 인증 헤더와 비교합니다.
- `ADMIN_TOKEN`: 필요할 경우 사용할 추가 관리자 인증값·세션 서명 비밀. 클라이언트 번들에 넣지 않습니다.
- `BUCKET`: Sites가 연결하는 R2 저장소. 무제한 무료가 아니며 저장량·요청·전송과 Sites 호스팅의 요금·쿼터를 확인해야 합니다.

외부 가입·구매·AI 호출은 수행하지 않았습니다. 원본 조사 기록은 `docs/SOURCES.md`에 있습니다.

## 평일 오전 9시 갱신

월~금 09:00 Asia/Seoul에 연결된 클라우드 작업이 `/api/updates/laws/run`을 실행합니다. 대상은 국세 6종·지방세 4종과 각 시행령·시행규칙, 하도급법·시행령 32종이며, 한 번에 16종씩 확인합니다(정기 실행은 하루 한 묶음, 관리자 화면은 전체). 정기 실행 때 최근 30일 판례 목록도 검토 대기로 확인합니다. 서버에 `HOLIDAY_API_KEY`(공공데이터포털 한국천문연구원 특일 정보)가 있으면 공휴일에는 건너뜁니다(`skipped-holiday`). 키가 없거나 특일 API가 실패하면 평소대로 실행합니다. 공개 여부와 관계없이 관리자 인증 또는 갱신 경로 전용 HMAC 서명을 서버에서 검증합니다. 예전 `UPDATES_OWNER_PRIVATE` 우회는 제거했습니다.

작업은 매 실행마다 native get_site로 현재 소유자·편집자 권한을 확인하고 서비스 접근값을 메모리에서 얻습니다. SHA256(`legal-updates-v1` + LF + project_id + LF + 서비스 접근값)으로 파생한 32바이트 키로 고정 갱신 경로·본문 해시·Unix 시각에 서명합니다. 서버는 `LAW_UPDATE_SIGNING_KEY` 비밀 환경값으로 서명과 5분 유효시간을 확인합니다. 키와 서비스 접근값은 파일·프롬프트·로그에 저장하지 않습니다. 서비스 접근값이 회전하면 서버의 파생 키를 재설정해야 하며, 일치하지 않으면 401로 중단합니다. 서명은 다른 관리자 API 권한을 부여하지 않습니다. 구체적 프로토콜은 `/api/updates/instructions`에 있습니다.

관리자 화면에 OC 발급·등록 안내와 암호화된 연결 설정을 추가했습니다. 수집된 법령 새 버전은 **법령 검토 대기**에서 공식 원문과 대조한 뒤 **전문 공개**하면 조문·부칙 전문 자료로 등록됩니다. 이미 앱에 있는 버전(법령명·시행일·공포일 동일)은 다시 저장하지 않습니다. 승인된 인증값이 없으면 상태는 `blocked`이고 공개 자료와 확인일을 바꾸지 않습니다. 신규 공식 API 응답은 이름·버전·시행/공포일·조문 본문을 확인한 후 R2에 검토 대기로 보관하며, 자동으로 법적 해설을 생성하거나 공개하지 않습니다. 초기 시드에는 공식 API 응답을 확인한 법령 조문·부칙 8건이 포함되어 있습니다. 이후 자동 갱신 실행은 연결 오류로 실패한 상태가 확인되었으므로, 현재의 자동 수집 성공·최신성을 보장하지 않습니다. 공휴일 제외는 특일 정보 키를 등록한 경우에만 적용됩니다.

OC 발급: https://open.law.go.kr/ 회원가입 → 활용 신청·조건 확인 → 승인된 OC 확인 → 앱 자료 관리의 법령 자동 갱신에 등록.


통합 인사이트의 키워드 검색은 확보한 법령 본문의 일치 조문·항·호를 법령별로 표시하며 같은 조문을 묶습니다. 항·호 버튼은 확보 원문의 행으로 이동합니다. 관계 법령 메뉴의 법령명 단위 목록은 유지합니다. 실무 자료에는 국세청 공식 링크 25건, 판례에는 기존 발췌 16건과 국세법령정보시스템 공식 상세 링크 8건을 수록했습니다.

판례 수집은 관리자 화면의 **판례 수집 · 최근 2년**에서 실행합니다. 2026-10-21 공식 API 응답을 확인한 결과, 국세법령정보시스템 판례 목록은 `법원명`을 비우고 법원을 사건번호(`대법원-2025-두-34754`)에 담으며, 본문(HTML) 요청은 국세청 사이트로 연결되는 안내 화면만 반환합니다. 따라서 법원·사건번호는 사건번호에서 분리하고 본문은 요청하지 않습니다. 선고일이 오늘 이후로 표기된 행 등은 해당 행만 제외하고 경고로 남깁니다. 대법원 출처 판례는 공식 JSON 본문(판시사항·판결요지·참조조문·전문, 16,000자 초과 시 앞부분 발췌)을 수록하고, 같은 법원·사건번호·선고일의 링크 자료가 이미 공개되어 있으면 본문을 보강합니다. 수집 자료는 검토 대기에 보관하고 관리자 확인 후 공개합니다. 실제 운영 서버에서의 수집 성공 여부는 OC 등록 후 화면에서 확인해야 합니다. 신규 유료 서비스·AI 호출은 추가하지 않았습니다.
